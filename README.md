EMR Instructor Reporting Solution

Project Overview

Business Problem:

•	Current OSCAR EMR reporting is limited for educational use.
•	Instructors have difficulty monitoring learner progress, competencies, and performance.
•	Manual reporting takes time.
•	It is difficult to identify learners who need support.


Proposed Solution:

•	Instructor dashboard
•	Learner performance analytics
•	Competency tracking
•	Customizable reports
•	Task completion tracking
•	Feedback/recommendations
